    Commands

    04 / commands

    Terminal

    Grouped by severity, evidence redacted, one line per finding.

    $ py -3 siteaudit.py https://example.com \
    --authorized --md report.md

[HIGH]  Exposed environment file (.env)
[HIGH]  Exposed Git repository metadata
[MED]   No Content-Security-Policy
[LOW]   Missing Referrer-Policy

Summary: 3 high, 4 medium, 3 low, 1 info
Grade D (55/100)

    JSON / Markdown

    Same data, machine readable, one file per run or one per inventory.

    {
  "target": "https://example.com",
  "grade": { "letter": "D", "score": 55 },
  "summary": { "high": 3, "medium": 4,
               "low": 3, "info": 1 },
  "findings": [
    { "id": "exposed-env",
      "severity": "high",
      "evidence": "SECRET_KEY=[redacted]" }
  ]
}

    Inventory

    Feed it a file. Anything outside the domain you declare is dropped before a request is sent.

    $ py -3 siteaudit.py --inventory sites.txt \
    --scope-domain example.com --authorized

hosts    : 12
skipped  : 2 (invalid or out of scope)
grade    : C (72/100)

    Window

    Target, audit, result. Same engine, no arguments.

    $ py -3 siteaudit_gui.py

    Two files, no install.

    Unzip, run py -3 siteaudit_gui.py for the window or py -3 siteaudit.py --help for the terminal. Standard library only, so there is nothing to pip.
